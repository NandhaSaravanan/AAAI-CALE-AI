Other deviations from the prompt:
- **Pairing.** Same-problem pairs are *positives* (per the prompt). They are used as A's only positive signal. In evaluation, the seen and held-out subsets use only transform positives; same-problem results are reported separately.
- **Matched FPR.** A pair is flagged if score > threshold; the threshold is set on val negatives (FPR ≤ 1% / 5%). Realized test FPRs are reported, e.g. Dolos 1.7% at the 1% threshold.
- **Main analysis subset.** The main analysis uses only pairs JPlag can score (both files ≥ 12 tokens; 72.1% of test pairs), applied to every detector. The all-pairs view is in `eval/view_all/`.
- **Bootstrap.** CIs come from 1,000 resamples over `source_group` (original program; a negative pair belongs to id_a's group), with thresholds fixed.

## 6. Open risks (weakest claims first)
1. **"Augmentation doesn't transfer" rests on one held-out family, one seed, one partially frozen encoder.** The +3.8-point CI excludes 0 but is small; with full fine-tuning or another seed it could change. Most-needed follow-up: 3+ seeds, and rotate which family is held out.
2. **Dead code is already easy for the learned models.** Zero-shot reaches 62.7% TPR@1%, and A 76.8%. That leaves little headroom for augmentation to show transfer, so the held-out test is weak.
3. **Reorder is nearly a no-op for mean-pooled embeddings** (zero-shot TPR@1% = 100%). B's seen-family gain comes almost entirely from renaming.
4. **Dolos's lead depends on the subset.** It is significant on JPlag-scorable pairs, but not on all pairs (CI includes 0). Dolos's realized test FPR at the 1% threshold is 1.7%, slightly favoring it. Dolos was also run in 150-pair chunks, which changes its fingerprint-frequency filter.
5. **Labels.** Same-problem positives teach the learned models to flag independent solutions. That is a deployment false-alarm risk, and it limits how A is interpreted.
6. **Not run.** Moss (no ID). JPlag normalization isn't available for Python.
7. **Equivalence** is checked only on sample I/O (1–3 cases per problem), not hidden tests.
8. **Bibliography.** 11 fields are unverified (see lit/refs.bib), and InvPT's "unseen family left open" caveat comes from a search snippet; the paper doesn't quote it.
9. **The PDF is a XeTeX preview.** Final pdfLaTeX output may reflow slightly; recheck the 4-page limit.
